2. 처리 목적과 항목

회사는 서비스 제공과 이용자 구성 분석에 필요한 범위에서만 개인정보를 처리합니다. 앱인토스 로그인 설정상 이름은 고정 필수 표시 항목이고, 성별·생년월일·내/외국인 구분은 필수 동의 항목으로 설정합니다. CI·이메일 주소·휴대전화번호는 요청하거나 수집하지 않습니다.

처리 목적처리하는 항목과 방식처리 시점
로그인·게임 저장·복구토스 앱별 이용자 식별값 및 이를 바탕으로 만든 앱인토스 전용 파생 계정 식별자, 인증·접속 상태, 게임 진행과 설정토스 로그인 및 저장 기능 이용 시
이용자 구성 분석성별, 생년월일(즉시 연령대로 변환하고 원문은 저장하지 않음), 내/외국인 구분, 수집 시각필수 동의 후 로그인 시
결제·환불·중복 지급 방지주문 번호, 상품, 지급·환불 상태 및 계정 연결 정보유료 상품을 실제 제공하는 경우
고객지원이용자가 직접 보낸 회신 주소, 문의 내용 및 필요한 주문 정보이메일 문의 시

이름과 생년월일의 처리 범위

토스 로그인 화면에 이름이 필수로 표시되더라도 회사 서버는 이름을 복호화하거나 저장하지 않습니다. 생년월일은 서버에서 한국 날짜 기준 연령대로 즉시 변환한 뒤 원문·암호문을 데이터베이스, 로그, 클라이언트 응답, 분석 전송에 남기지 않습니다. 성별·연령대·내/외국인 구분과 수집 시각만 서울 리전 Firestore의 서버 전용 경로에 저장하며, Firebase Authentication에는 이 분석 정보를 전송하지 않습니다.

3. 보유 기간과 파기

정보보유 기간·파기
게임 진행·계정 연결 정보서비스 이용 중 보유하며, 탈퇴 시 진행 삭제와 접근 차단을 처리합니다. 단순 토스 연결 해제는 탈퇴와 구분되어 게임 진행은 유지될 수 있습니다.
이용자 구성 분석 프로필마지막 정상 로그인부터 연결 해제 또는 탈퇴 처리까지 보유합니다. 연결 해제와 탈퇴 시 삭제합니다.
원문 생년월일·이름·CI·이메일·휴대전화번호원문 생년월일과 이름은 저장하지 않으며, CI·이메일·휴대전화번호는 요청하지 않습니다.
Firebase Authentication 정보탈퇴 처리 후 Firebase Authentication의 운영·백업 시스템에서 최대 180일 안에 제거될 수 있습니다. Firebase가 보안·오용 방지 목적으로 기록하는 IP 주소는 수 주간 보관될 수 있습니다.

결제 및 분쟁 기록

유료 상품은 아직 제공하지 않습니다. 제공하는 경우 전자상거래법 시행령 제6조에 따라 표시·광고 기록은 6개월, 계약 또는 청약철회 기록과 대금결제·재화 등의 공급 기록은 5년, 소비자 불만 또는 분쟁처리 기록은 3년 보존합니다.

4. 처리위탁과 국외 이전

처리위탁

수탁·서비스업무처리 위치·범위

국외 이전 고지와 동의

Firebase Authentication에 대한 별도 필수 국외 이전 동의는 개인정보 국외 이전 동의에서 받습니다. 이전 항목은 토스 앱별 이용자 식별값을 바탕으로 만든 앱인토스 전용 파생 계정 식별자, 앱 식별 정보, 그리고 인증 과정에서 Firebase가 자동 수집하는 IP 주소·사용자 에이전트입니다. 이름, 성별, 원문 생년월일·암호문, 연령대, 내/외국인 구분, CI·이메일·휴대전화번호를 미국 Firebase Authentication으로 이전하지 않습니다.

5. 이용자의 권리와 행사 방법

이용자는 자신의 개인정보에 대해 열람, 정정·삭제, 처리정지 또는 동의 철회를 요청할 수 있습니다. 토스 앱 설정에서 로그인 연결을 해제하거나 토스 로그인 약관 동의를 철회할 수 있으며, 계정·게임 진행의 삭제와 개인정보 관련 요청은 helpyjs@gmail.com으로 할 수 있습니다. 로그인 연결 해제 시 분석 프로필을 삭제하고 세션·토큰 후속 처리를 합니다. 법정 보존 대상이 있는 경우에는 해당 기록을 다른 정보와 분리하여 법정 기간 동안 보관합니다.

6. 안전성 확보 조치

분석 프로필은 서버 전용 경로에서만 처리하고, 원문 생년월일·이름·암호문을 저장 또는 분석 로그 전송하지 않습니다. 전송 구간 보호, 접근 권한 관리 및 계정별 접근 차단을 적용합니다.

7. 방침 변경

이 방침을 변경하는 경우 변경 내용과 시행일을 이 페이지에서 안내합니다. 수집 항목, 국외 이전, 결제, 보유 기간처럼 이용자에게 중요한 변경은 실제 적용 전에 방침과 필요한 동의 절차를 함께 갱신합니다.
