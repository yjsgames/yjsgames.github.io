2. 처리 목적과 항목

회사는 서비스 제공에 필요한 범위에서만 개인정보를 처리합니다. 현재 앱인토스 로그인 설정은 성별·생년월일·내/외국인 정보를 필수 동의 항목으로 준비하고 있으며, CI·이메일 주소·휴대전화번호는 요청하지 않습니다.

처리 목적항목과 방식처리 시점
로그인·게임 저장·복구토스 앱별 이용자 식별값, 파생 계정 ID, 인증·접속 기록, 게임 진행과 설정토스 로그인과 게임 저장 기능이 실제로 활성화된 경우
이용자 구성 분석성별, 생년월일에서 변환한 연령대, 내/외국인 구분, 수집 시점이용자가 토스 로그인 동의 절차를 완료하고 기능이 활성화된 경우
결제·환불·중복 지급 방지주문 번호, 상품, 지급·환불 상태 및 계정과의 연결 정보유료 상품 기능이 실제로 제공되는 경우
고객지원이용자가 직접 보내는 회신 주소, 문의 내용, 필요한 주문 정보이용자가 이메일로 문의하는 경우

생년월일 원문과 이름

토스 로그인 화면에서 이름은 필수 항목으로 표시되지만, 회사 서버는 이름을 복호화하거나 저장하지 않습니다. 생년월일은 서버에서 연령대로 변환하는 데만 사용하며, 원문 생년월일·암호문·이름은 회사의 데이터베이스, 클라이언트 응답, 분석 로그에 저장하지 않습니다. 연령대는 마지막 정상 로그인 시점의 한국 날짜를 기준으로 계산됩니다.

3. 보유 기간과 파기

정보보유 기간·파기
게임 진행과 계정 연결 정보서비스 이용 중 보유하며, 이용자가 탈퇴하면 진행 삭제와 접근 차단을 처리합니다. 단순한 토스 로그인 연결 해제는 탈퇴와 구분되며, 게임 진행은 유지될 수 있습니다.
이용자 구성 분석 프로필마지막 동의·로그인부터 연결 해제 또는 탈퇴 처리까지 보유합니다. 연결 해제와 탈퇴 시 분석 프로필을 삭제합니다.
원문 생년월일·이름·CI·이메일·휴대전화번호회사는 원문 생년월일과 이름을 저장하지 않으며, CI·이메일·휴대전화번호는 요청하지 않습니다.
Firebase Authentication 정보계정 삭제 요청 시 Firebase Auth 사용자 삭제를 요청합니다. Firebase 안내에 따르면 삭제 요청 뒤 인증 정보는 운영 시스템과 백업에서 최대 180일 안에 제거될 수 있습니다.

결제·환불 기록 및 고객지원 문의의 법정 보존 근거·항목·기간은 아직 운영 확정 전입니다. 해당 기능을 실제로 시작하기 전에 적용 법령과 실제 처리 범위에 맞춰 이 방침에 구체적으로 반영합니다. 법령에 따라 보존이 필요한 정보는 그 근거와 항목, 기간을 함께 안내한 뒤 별도 보관합니다.

4. 처리위탁과 국외 처리

처리위탁

서비스가 활성화되면 회사는 게임 저장·계정 인증을 위해 Google Firebase를 사용합니다. Firebase는 회사가 정한 목적과 범위에서 서비스 운영을 지원하는 처리위탁 수단입니다.

수탁·서비스업무현재 구성
Google Firebase / Cloud Firestore게임 진행, 서버 전용 분석 프로필의 저장게임 진행과 이용자 분석 프로필은 서울 리전에서 보관하도록 준비하고 있으며, 아직 실사용자 정보의 저장을 시작하지 않았습니다.
Google Firebase / Authentication계정 인증과 계정 관리Firebase 공식 안내상 Authentication은 미국 데이터센터에서만 처리됩니다.

국외 처리 관련 고지

Firebase Authentication은 미국에서만 처리된다고 Firebase가 안내합니다. Firestore 인스턴스의 서울 리전 설정만으로 모든 개인정보가 국내에서만 처리된다고 설명하지 않습니다. 현재는 실제 이용자 정보의 수집을 시작하지 않았으며, 앱인토스 로그인 활성화 전에 국외 이전에 필요한 고지·동의 여부, 수탁자 연락처, 이전 항목·시기·방법·보유 기간을 실제 계약과 설정에 맞게 확정합니다.

5. 이용자의 권리와 행사 방법

이용자는 자신의 개인정보에 대해 열람, 정정·삭제, 처리정지 또는 동의 철회를 요청할 수 있습니다. 계정 삭제는 게임 안의 절차로 요청할 수 있으며, 게임 접근이 어려운 경우 helpyjs@gmail.com으로 요청할 수 있습니다. 요청 내용과 본인 확인에 필요한 최소한의 정보를 확인한 뒤 관련 법령과 서비스 운영 범위에 따라 처리합니다.

6. 안전성 확보 조치

회사는 서버 전용 경로로 분석 프로필을 다루고, 원문 생년월일을 저장하지 않으며, 접근 권한과 전송 구간 보호 조치를 적용합니다. 구체적인 기술 구성은 보안상 필요한 범위에서 운영 환경에 맞춰 관리합니다.

7. 방침 변경

이 방침을 변경하는 경우 변경 내용과 시행일을 이 페이지에서 안내합니다. 로그인 수집, 결제, 국외 처리, 보유 기간처럼 이용자에게 중요한 내용이 확정·변경되면 실제 적용 전에 방침과 필요한 동의 절차를 함께 갱신합니다.
