# Slugger 모바일 개인정보 고지

사용자 요청인 네이티브 광고와 광고 제거·리워드 즉시 수령 구매/복원 연결에 필요한 공개 URL이다. Rubble 페이지의 스타일·지원 연락처를 재사용하고 Slugger 실제 처리만 부모가 작성했다. 게임 진행의 클라우드 저장·Google/Apple 로그인·익명 계정은 제공한다고 쓰지 않았다.

- 원본: `YJS-Games/slugger`의 `SluggerPurchaseAccount`, `SluggerMobileBilling`, `SluggerGame.Mobile`, `SluggerNativeAds`, `SluggerMobileAdsBootstrap`, `server/store-validation`.
- 2026-11-13 사용자 결정: 아동·청소년·성인 혼합. 최초 1회 연령대 선택과 보호 광고. Slugger Firebase Blaze 전환과 서울 리전 검증 서버 2개 배포 승인.
- 현재 Firebase `kiwogi-slugger`, Auth email/password, 서울 Firestore 및 검증·삭제 함수가 활성 상태다. 게임 진행은 기기에 저장하며 구매 권리는 별도 계정에 연결한다.
- 연락처와 운영자 표기는 기존 Rubble 공개 고지와 동일한 YJS Games / helpyjs@gmail.com이다. 현재 Slugger 구매 계정 삭제는 재인증 후 서버 삭제·권리 해제, 기기 세이브 삭제는 별개다.
- SDK 원문: [Firebase](https://firebase.google.com/support/privacy), [UMP](https://developers.google.com/admob/unity/privacy), [Unity 이용자 개인정보](https://unity.com/legal/game-player-and-app-user-privacy-policy). 법률상 특정 보관 기간이나 모든 제공업체 데이터 즉시 삭제를 단정하지 않았다.

공개 URL: `https://yjsgames.github.io/slugger/privacy/`, 삭제 안내 앵커 `#delete-account`. 원문·한국어 작은 화면·실제 공개 응답을 검수하며 상품/광고 송출의 완료와 별도로 기록한다.
